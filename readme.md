# 233猜想的验证算法

## 验证迭代
n_{k+1}=10P^+(n_k)+r(P^+(n_k))
其中 P^+(n) 为最大质因数，r(n)=n\bmod 10。
终止条件：某步 P^+(n_k)=233，则下一步进入 233 循环。

## 质因数分解

1. 先试除 5000 以内预筛素数。
2. 余数用 7 基 Miller-Rabin 做确定性素性测试（适用于 n<2^{64}）。
3. 合数用 Brent-Pollard rho 分解；参数 c 递增重试并设 r 上限，避免原版固定 c 导致的死循环。
4. 递归/栈式分解，取最大质因数。

## 迭代与记忆化

· 每步记录 n、P^+(n)、n_{k+1}。
· 起始值为 233 时跳过首次命中，避免误判。
· 固定容量开放寻址哈希缓存所有已验证到达 233 的数；迭代中命中缓存直接判成功。
· 缓存满后停止插入，内存有界，不影响正确性。

## 并行与输出

· 按区间分块多线程；原子计数器汇总进度，互斥锁保护共享缓存。
· result.txt 仅输出：范围、总数、成功数、失败数、失败值列表，无歧义。

## 复杂度
分解期望亚指数；整体近似线性。1e8 规模在个人多核机上通常分钟级完成。
